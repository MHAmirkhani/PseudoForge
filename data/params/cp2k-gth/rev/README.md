# CP2K GTH Revision Benchmark Data

The file `Delta-test_GTH_rev_ABINIT.md` in this directory is upstream
benchmark data from the CP2K data repository:
<https://github.com/cp2k/cp2k-data/tree/master/potentials/GTH_rev/ABINIT/PBE>

It records reference Delta-gauge verification results computed with ABINIT
against all-electron data. It is kept as scientific parameter data shipped
with the library, not as PseudoForge documentation.
