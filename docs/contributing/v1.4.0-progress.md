- **Key Scientific Findings**:
  - **Preregistration**: ACWF FLEUR/WIEN2k all-electron reference equation of state ($V_0 = 47.8266\text{ \AA}^3$, $B_0 = 0.36774\text{ eV/\AA}^3 = 58.918\text{ GPa}$, $B'_0 = 4.8620$, dataset file `results-unaries-verification-PBE-v1-AE-average.json`, SHA-256 `d7844caa127eae860fe5087ead42f80d1b6b5eb952a686ff4b912ddaed7db48b`).
  - **Arm A (Baseline unrepaired)**: Omitting `LLocal` produces an ill-defined Kleinman–Bylander projector leading to complete lattice instability (monotonically declining energy with expanding volume; worst EOS error $\sim 2810\text{ meV/atom}$).
  - **Arm B (Single-engine repair `LLocal = 0`)**: Eliminates the $s$-channel bound ghost, but induces a severe negative ghost state in the $p$-channel ($E_{ref} > E_0, KB < 0$), causing total energies to diverge pathologically ($+92,079\text{ Ry}$) and destabilizing consumer SCF.
  - **Arm C (Cross-engine repair from ONCVPSP donor)**: Direct parameter transplantation ($r_c = 2.0, 2.2, 2.0\text{ bohr}$) fails APE generation (`Unable to bracket eigenvalues for state: 1s`) due to the filled $3d^{10}$ semicore shell. Expanding cutoffs to $+20\%$ ($r_c = 2.4, 2.64, 2.4\text{ bohr}$) permits generation, but yields unphysical overbinding ($+208,802\text{ Ry}$).
  - **Scientific verdict**: Definite null/negative transferability result across chemical rows; demonstrates why automated parameter transplantation cannot be claimed universally.
