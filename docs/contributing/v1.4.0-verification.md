- Cross-engine parameter transplantation (Arm C) successfully eliminates the $s$-channel ghost state (achieving Level L4), but its material accuracy at standard plane-wave cutoffs ($E_{\rm cut} = 40$~Ry) is **36.81 meV/atom**, which does **not** pass the strict 2.0 meV/atom threshold for Level L5.
