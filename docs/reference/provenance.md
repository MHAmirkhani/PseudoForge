# Provenance

`pseudoforge provenance` inspects and reports the exact origin, generation parameters, binary checksums, and upstream attributions of a pseudopotential file in the PseudoForge store.

---

## Synopsis

```bash
pseudoforge provenance <file-id> [--json]
```

### Arguments and options

| Argument / Flag | Description |
|---|---|
| `<file-id>` | **Required.** Filename or store identifier (e.g. `Si.pbe-n-oncv.UPF` or `adpack_nc_pbe_full_pseudos_Ag.rel-pbe-adpack.vps.gz`). |
| `--json` | Emit full record and raw provenance as a structured JSON object. |
| `-h, --help` | Show command usage. |

---

## Output Fields

A provenance report contains:

- **Element**: chemical element symbol, name, and atomic number $Z$.
- **Family**: norm-conserving (`NC`), projector augmented-wave (`PAW`), or ultrasoft (`US`).
- **Functional**: exchange-correlation parametrization (e.g. `PBE`, `PBEsol`, `LDA`).
- **Relativity**: relativistic treatment (`scalar`, `full`, or `nonrel`).
- **Profile**: library profile from which the deck was drawn (e.g. `pseudodojo`, `psl-high`).
- **Engine**: generator engine name and version (e.g. `ONCVPSP 4.0.1`, `Quantum ESPRESSO ld1.x`).
- **Binary SHA256**: SHA-256 fingerprint of the generator binary that compiled the file.
- **Build date**: ISO 8601 timestamp of generation.
- **Source**: upstream source attribution.
- **Generated by**: exact command line that generated or reproduced the file.
- **Format**: output file format (`upf`, `psml`, `psp8`, `vps`, `xml`, etc.).
- **Size & SHA256**: exact byte count and cryptographic hash of the served artifact.

---

## HTTP API

```http
GET /api/provenance/:id
```

Returns `200 OK` with JSON fields matching the CLI, plus the complete raw `PROVENANCE.txt` contents under `"raw"`.
