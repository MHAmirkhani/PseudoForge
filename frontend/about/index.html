About PseudoForge

A Bash-native, multi-engine pseudopotential generator, validator and converter. It drives nine atomic-structure codes from one interface, checks what they produce, converts between formats when that is honest, refuses when it is not, and records in every output exactly what made it.

What this site is

A shop front and a converter, not a compute service. It serves pre-built native files and converts them on demand.

Generation runs on your machine. This is a one-core VPS with no engines and no Quantum ESPRESSO, and that is a design decision rather than a limitation being worked around — queueing a job no worker would ever collect would look like it worked. The reasoning.

What it will not do

Convert a file into something it is not. A GTH pseudopotential is a dozen analytic coefficients; a UPF is a radial table. Turning one into the other means constructing a new pseudopotential and labelling it with the original's name. The API refuses, with the reason — each refusal is documented.

Silently substitute a functional. Eight of the nine engines have no meta-GGA path. Ask one for r2SCAN and you get a PBE dataset intended for use with r2SCAN — which is standard practice — and a note saying so, in the report and in the provenance.

Claim a library's name for a file that library did not produce. The shipped recipes are byte-identical to PSlibrary's own inputs except where ERRATA.tsv declares a correction — two decks, both caesium, both recorded with the measurement behind them.

Citation

PseudoForge implements no pseudopotential method. It drives codes written by the people who developed them, and publishing work made with one means citing that code's authors. 

pseudoforge citation --all

Every generated project also gets a CITATION.txt and a LICENSE.txt in its pseudos/ directory, so the attribution travels with the files rather than staying behind in the terminal.

PseudoForge itself has no DOI yet, and its citation metadata says so rather than carrying a placeholder.
