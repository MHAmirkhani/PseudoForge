Validate a pseudopotential

Drop a UPF, PSP8, PSML, GTH, CPI, FHI, RRKJ3 or VPS file. The panel below shows what the file declares about itself before you ask for a check, and the check reports whether those declarations hold together. No engine runs; nothing leaves this server.

What the file says about itself

Read straight out of the file's own header. These are declarations, not findings — the button above is what checks them.

Radial data

Read straight from the file. The local potential shows the shape of the pseudopotential, the wavefunctions show the node structure of each l channel, and the density shows where the valence electrons sit.
